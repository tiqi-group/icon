The experiments page shows a list of experiments on the left. This list is parsed from the experiment library ICON connects to.

Use the star beside an experiment to pin it to Favorites at the top of the list.
Pinning does not open the experiment or change its group assignment. Unpinning
returns it to its original group, respecting that group's collapsed state.
Favorites are sorted alphabetically and stored in the current browser, separately
from experiment groups. They are synchronized across tabs on the same origin.

To pin several experiments, mark them with Ctrl+click or Shift+click, then use
`Pin to favorites` in the right-click menu. If every marked experiment is already
a favorite, the menu instead offers `Unpin from favorites`. Temporarily unavailable
experiments are hidden without forgetting their favorite status. If browser
storage is unavailable, pinning still works for the current page session.

When you click on an experiment, you will be greeted with the scan interface on the top. This allows you to define parameters you want to scan, the priority of the scan (number between 1 and 20), the number of shots for each data point, and the number of scan repetitions.

On the bottom, you will get the display groups defined for the experiment (instance). These are either local parameters (i.e. parameters scoped to the experiment instance), global parmaeters (i.e. parameters that) or device parameters
