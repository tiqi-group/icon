# Compact Accent

A light-mode variant of Compact Light with clearer unit badges, a selection
rail for experiments and jobs, and a divider on parameter group headers.

Select **Settings → Browser → Style → Compact Accent**. The preset imports
Compact Light from the same ICON installation. If the site overrides Compact
Light with a user stylesheet, Compact Accent extends that version.

Unit labels use standard ICON parameter types. Their text remains visible, and
the badge stays neutral when the input is scanned, stale, or invalid. The
preset uses the stock widgets and works with standard experiment metadata.
